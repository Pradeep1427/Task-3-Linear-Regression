# Task 3 - Linear Regression

## Objective
Implement and understand simple and multiple linear regression.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Steps Performed
1. Imported the dataset
2. Preprocessed the data
3. Split the dataset into training and testing sets
4. Built a Linear Regression model
5. Trained the model
6. Made predictions
7. Evaluated the model using MAE, MSE and R²
8. Plotted the regression line
9. Interpreted the model coefficients

## Evaluation Metrics
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score

## Conclusion
Linear Regression was implemented to predict house prices and the model was evaluated using standard regression metrics.
